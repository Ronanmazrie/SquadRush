# 装備合成・一覧・ステージ絵（0.10.0）

- 同じ装備ID・同じレアリティ3個 → 次のレアリティ1個。白・緑・青・紫・金の5段階、効果倍率1/2/3/5/8。最高段階は合成不可。
- 重複報酬も1個ずつ保存。装備中の素材を合成すると装備先を強化後へ引き継ぐ。素材不足・別種類・別レアリティ・無効IDでは消費しない。戦闘中の合成も拒否。
- 既存のEquipment.v1キー内でversion 1のビットマスクをversion 2の個数配列に一度だけ移行。所持品・3つの装備枠・進行を維持。未取得品の自動装備はしない。
- 5列のアイコン一覧、個数、レアリティ色、装備中・合成可能を表示。種類とレアリティが同じ物はスタック表示。最大30スタックを縦スクロールで閲覧。
- 合成の消費数と結果の効果をプレビューし、合成後は結果の詳細へ移る。未所持・最高段階は適切にボタンを無効化。
- ホームとステージ選択は6枚の異なる2D環境イラストを使用。7以降は6枚を繰り返す。戦闘は既存の3Dとランダム生成を維持。ガチャは未実装。

Unity 6000.3.26f1の検証用プロジェクトで76件のゲーム処理と68件の再生モード検証に合格。各種合成、データ移行、再読込、実弾ダメージ、30スタック表示、スクロール末尾の詳細、ステージ絵6枚の識別、文字の収まりを確認。検証は専用GUIDキーを使用し、ユーザーのセーブを消去しない。

画像は内蔵image_genで作成。素材はAssets/Resources/StageArt、再生成用のコピーはSquadRushPrototype/StageArt、生成指示はstage-art-prompts.jsonに保存。Tripoの生成・処理は実行していない。
