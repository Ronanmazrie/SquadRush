# Rounded character models — 0.8.0

Date: 2026-10-16. Unity 6000.3.26f1.

Characters use locally generated connected ring surfaces rather than box-shaped faces, limbs and boots. A tapered torso, shaped jaw/forehead, eyes/nose/mouth, curved sleeve paths, rounded helmet, backpack, vest and boot profiles form the new silhouette. The blue and red uniforms and boss insignia remain distinct. A stable frame along curved limbs avoids a twist as the tangent crosses downward. Character materials use thinner outlines and less shine while scenery keeps its existing material settings.

Body, two legs, muzzle and weapon-upgrade attachments remain compatible with the existing simulation-driven animation. Stride and bounce are softer, and pooled actors now reset their body/leg pose as well as their flash. Home and equipment render the same updated original model. Gameplay, hitboxes, equipment saves and the 3-HP normal-enemy balance are unchanged.

Actual mesh budget: 4,388 body triangles plus two 616-triangle legs = 5,620 triangles per regular soldier. The three solid renderers and shared team mesh/material instances remain bounded. No per-frame mesh generation or external runtime loader was added.

64 gameplay scenarios and 41 Play-mode scenarios pass. Character-specific checks cover shared meshes across all 96 allies, the triangle/renderer budget, finite vertices/normals, ground/portrait bounds, and pooled pose reset. Existing 1000-ally combat and reward/menu checks still pass.

Tripo was explicitly requested, then limited by the user to free functionality. The official CLI doctor and dry-run planning commands were used. API generation and rigging spend credits and were not submitted; the user did not authorize the proposed 65-credit chain. Tripo generation/processing spend: 0 credits, with no paid task ids. Final character meshes were created locally in SquadRushCharacterMeshes.cs, not generated by Tripo. No external asset licence or network access is needed for the resulting game art.

Browser and APK distribution checks are recorded separately. Physical Android/iPhone performance and Safari remain untested.
