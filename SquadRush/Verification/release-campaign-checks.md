# 恒常ガチャ・リリースキャンペーン（0.13.0）

- 現在のガチャを恒常ガチャとして継続し、ガチャ内に「恒常ガチャ」「イベント」のタブを設置。
- イベントにリリース記念の無料10連チケット配布を実装。ホームからも入れます。
- チケット10枚を1回だけ受取。受取フラグとチケット残高を既存のAccount.v1にまとめて保存し、旧データにも自動付与せず受取可能な状態で追加。
- 受取ではジェム・コイン・キャラ・天井・抽選回数を変更しません。受取後のボタンからチケットモードの恒常ガチャへ移動し、通常の10回引くで抽選します。
- 恒常ガチャの排出内容・確率・天井を変更せず、無料チケットの10連も同じ保存・武器付与処理を通します。
- 重複受取を防ぎ、再起動・日付変更・ログイン報酬から独立して受取状態を保持。
- チケット上限まで10枚分の空きがない場合は受取を保留し、報酬を欠損させません。戦闘中のイベント遷移・受取も防止。
- 受取可能通知、受取済みボタン、ホームの受取済み表示を連動。
- 終了日は未定。オンラインアカウントの実装はなく、受取制限は各端末のセーブデータ単位です。
- ゲーム処理130件・Playモード98件、計228件成功。旧データ・受取連打・再読込・日付変更・上限境界・10連の実報酬・チケット消費・ジェム維持・恒常とイベントの操作範囲を確認。
