# UIアイコン・画面整備（0.12.0）

- 既存のuGUIを維持し、SquadRushUiIconのベクター描画を21種類へ拡張。オリジナルの輪郭、配色、陰影、ハイライトを共通化。外部生成サービスの利用・クレジット消費はありません。
- 通貨：ジェム、チケット、コイン。名前・桁区切り付き残高と分けて表示。
- ホーム：キャラ、プレゼント、ミッション、出撃。受け取れるログイン・ミッション報酬の目印。
- ログイン：通貨ごとの数量、7日分の報酬、受取済みチェック、当日行の強調。
- ミッション：種類別アイコン、ジェム報酬、達成率のバー。
- キャラ：所持チェック／未入手の鍵、応急補給・爆裂掃射・電光連射のスキル絵。
- 装備：未装備枠の種類、威力・仲間・連射の能力値、合成。既存の6枚の装備絵を維持。
- ガチャ：通貨の選択、コイン排出のイラスト。確率・天井・消費・報酬・保存形式は従来どおり。
- 21種類すべての形状が異なり、頂点が有限・矩形内で、タッチを遮らないことをPlayモードで確認。
- 凹形状はear clippingで三角形化し、切り欠きや星形を正しく描画。共通のUIマテリアルを使用。
- 390×844でホーム・ガチャ・キャラ・ログイン・ミッション・装備・10連結果の文字のはみ出しを検査。
- ゲーム処理120件、Playモード90件（合計210件）成功。GUID付き検証用データを使い、プレイヤーの保存を変更しません。
- Preview/icons.png、home-mobile.png、login-mobile.png、missions-mobile.png、characters-mobile.pngなどを目視確認。

ブラウザ・APKの配布検証はweb-checks.txtとandroid-checks.txtに記録。実機のAndroid・iPhone・Safari確認は未実施です。
