# キャラ・ガチャ・通貨・報酬（0.11.0）

初期の青い兵士をレンとして維持し、アカネとミオをガチャで追加。レンは仲間3人補給、アカネは全敵への10＋武器威力×5ダメージ、ミオは6秒の連射＋50%。クールダウンは12/16/18秒。選択キャラを保存し、装備画面の肖像と戦闘の隊長の服色にも反映する。スキルは戦闘ボタンから手動発動する。

ガチャ1回はチケット1またはジェム100。10連は10倍。通貨は明示選択し、残高不足で他通貨を消費しない。キャラ枠の合計確率は1～79連0.5%、80～89連は0.005＋0.05×（連数－79）、90連は100%。キャラ排出でカウントをリセットし、10連も1回ずつ判定。未所持キャラを優先して均等抽選し、全所持後の重複は1000コインへ変換する。

キャラ以外は残り確率を半分ずつ基本武器／200コインに分ける。武器はノーマルのスカウト／アサルトを均等抽選し、既存の合成素材に使える。ウォレット・キャラ・天井・結果と付与待ち武器を先に記録し、取引ID付きの装備付与で中断時にも二重付与や再消費を防止する。最後の結果を再表示できる。

ログインは日本時間0時で更新、1日1回の受取。通常100ジェム・チケット1、7回目は300・3、以後循環。連続条件なし。クリアは毎回100ジェム・50コイン、初クリアはさらに100ジェム。毎日のクリア1回／敵50体／ガチャ1回と恒久のSTAGE 03クリアでジェムを受け取れる。撃破は勝敗が決まった戦闘結果で集計。

保存先は既存の進行キー＋Account.v1。既存の装備・ステージ進行・初期キャラを維持。UTC時計を日本時間へ変換する端末保存の試作で、オンライン認証・購入・広告は追加していない。時計を戻す操作ではログイン再取得・日替わりリセットを発生させない。

Unity 6000.3.26f1で120件のゲーム処理・89件の再生モード検証に合格。確率境界、80/90連、10連内天井リセット、通貨別消費、素材付与、重複変換、日付・二重受取、再起動・取引復旧、実敵ダメージ・連射時間、UI操作、390×844の結果表示、シェーダーのコンパイルを検証。テスト用GUIDキーを使用しユーザーのセーブは消去しない。

新キャラの画像は内蔵image_genで作成。EquipmentArt/akane.png・mio.pngとソースキットArtに保存。正確な生成指示と元画像パスはcharacter-art-prompts.json。Tripoの有料生成・処理は使用していない。
