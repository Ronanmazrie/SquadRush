# スクワッド・ラッシュ

Unity 6.3 LTS `6000.3.26f1` で作成した縦画面のスマホゲーム試作です。Android / iPhoneを対象とし、広告・課金はありません。

## 開く場所

プロジェクトフォルダー：`C:\Users\wakam\OneDrive\ドキュメント\ChatGPT\ゲーム開発\SquadRush`

Unity Hubで「Add / ディスクから追加」からこのフォルダーを選ぶか、Unity Editorでこのプロジェクトを開きます。`Assets/Scenes/SquadRush.unity` をダブルクリックし、上部の ▶ Play、その後ホーム上部のステージ名を開いて選ぶか、中央下の「出撃」を押してください。

簡単に起動するには、Unityが閉じている状態で、親の「ゲーム開発」フォルダーにある `Start-SquadRush.cmd` をダブルクリックします。インストール済みのUnity本体を直接起動し、試作シーンを再生します。ホーム上部のステージ名を開いて選ぶか、中央下の「出撃」を押してください。

すでにUnityが開いている場合は、上部メニューの `Squad Rush > Play Prototype` を選びます。シーンを探して開く操作は、このメニューが自動で行います。Unityの起動ログは `Logs/editor-session.log` に保存されます。

## 遊び方

- ホーム上部のステージ名で解放済みステージを選び、「出撃」で開始します。下部のタブでガチャ・出撃・装備を切り替えます。ガチャは準備中の画面のみです。
- ステージクリアで装備を入手し、下部の「装備」でアイコンをタップして詳細を開き、武器・防具・サポートを1つずつ付け替えます。所持・装備状態は保存され、以前のクリア報酬も受け取れます。
- マウスを左右にドラッグ、左右矢印、A / Dで部隊を移動。スマホでは指のドラッグに対応。
- 射撃は自動。青い加算・倍率ゲートを選ぶと味方が増えます。
- 仲間の上限は1000人。青い補給BOXは仲間が4人以上（部隊の約10％）増え、金色は威力、緑色は連射が強化されます。敵や箱との接触、赤い減算ゲートで味方が減ります。
- BOXの武器強化は各5段階。次のステージ・再挑戦ではBOX強化を初期化しますが、装備の効果は残ります。最大時の同種BOXは仲間補給になります。
- 仲間が0人になると同じステージを再挑戦。終盤のボスを倒すとクリアし、「次のステージへ」で先へ進みます。
- 景色は砂漠・森林・雪原で切り替わり、挑戦ごと・背景の折り返しごとに配置を再生成します。進行はクリア時に端末内へ保存します。
- 地面の模様も背景や白線と同じ速度で流れます。「Ⅱ」で一時停止し、「ホームへ」で出撃を終了してホームへ戻れます。バックグラウンド移行時にも一時停止します。

## 検証とビルド

コンパイル、ゲーム処理64ケース、再生モード50ケースを確認済み。`Verification/` に結果と画面プレビューがあります。人数は1000まで数え、描画は96体まで・弾は1斉射40本までの代表表示で全員分の攻撃力を反映します。Android APKとブラウザ版をGitHubで配布しています。スマホ実機での確認は未完了です。

Android Build Support（SDK / NDK / OpenJDKを含む）を追加後、`Squad Rush > Build Android APK` でビルドできます。iOS Build Supportを追加後、`Squad Rush > Export iOS Xcode Project` で出力できます。iPhone実機用の最終ビルドにはMacのXcodeと署名設定、または対応するクラウドビルド環境が必要です。

編集するゲーム処理は `Assets/Scripts/SquadRushGame.cs`、画面表示は `Assets/Scripts/SquadRushHud.cs` にあります。参考画像の仕組みをもとに、オリジナルのプログラム生成モデルで実装しています。フォントはNoto Sans CJK JP（SIL OFL）、ライセンスは `Assets/Fonts/LICENSE.txt` です。

プロジェクトと再生成用ソースキットは親フォルダーのGitで管理します。Assetsの変更時は `.meta` ファイルも一緒に保存してください。
