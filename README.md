# スクワッド・ラッシュ / Squad Rush

敵を自動射撃しながら仲間を増やす、Unityの縦画面ゲームです。広告・課金なしの試作0.14.0。

- [ブラウザで遊ぶ](https://ronanmazrie.github.io/SquadRush/play/)
- [Android版をダウンロード](https://github.com/Ronanmazrie/SquadRush/releases/download/v0.14.0/SquadRush-Android.apk)
- [配布ページ](https://ronanmazrie.github.io/SquadRush/)

AndroidアプリはAndroid 8.0以降・ARM64向け。iPhoneはブラウザ版をご利用ください。iOSネイティブアプリは未配布です。

## 画面と操作

下部に「ステージ・装備・キャラ・ガチャ・ミッション・メール」の6タブを常設。各画面へ1回で移動し、他の場所に重複した画面ショートカットを置きません。ステージ画面の左右矢印で解放済みステージを選び、「出撃」。戦闘中はタブを表示したまま操作を無効にし、一時停止後のタブ選択で戦闘を終了して移動できます。結果・装備詳細・ガチャ結果でもタブを残しています。

移動は指の左右ドラッグ。PCではマウス、左右キー、A / Dにも対応。射撃は自動。ゲートや補給BOXで仲間・威力・連射を育てます。仲間は1000まで計数し、描画は96体・代表弾40本にまとめて全員分の攻撃力を反映します。地面・背景はスクロールし、景色の配置は挑戦ごとに変化します。

## 恒常・イベントガチャ

ガチャ内で「恒常ガチャ」「イベント」を切り替えます。イベント「紅蓮作戦」はアカネを対象にした実際のガチャです。両方ともチケット1枚またはジェム100個で1回、10枚または1000個で10回。キャラ確定までの残り回数を表示し、恒常とイベントの天井は別々に保存します。キャラ確率の数値・次回確率・提供割合画面は表示しません。

恒常はアカネ・ミオ、イベントのキャラ枠はアカネ。その他は基本武器またはコイン。所持済みキャラはコイン1000に変換します。ゲーム内通貨のみで、実際の購入処理はありません。

初期キャラのレンは仲間を3人補給。アカネは敵全体への範囲攻撃、ミオは6秒間の連射強化を使えます。キャラタブで選択し、戦闘画面のスキルボタンで発動します。

## ミッション・メール

ミッションタブでデイリー・恒久ミッションを管理し、内部の「ログイン」タブで7日分のログイン報酬を受け取れます。日本時間0時で日付を更新します。

配布報酬はメールへ集約。リリース記念のチケット10枚は、メールから1セーブデータにつき1回受取。恒常・イベントの両方で使えます。0.13.0で受け取ったプレイヤーは受取済みのまま引き継ぎ、重複付与しません。受取だけでは抽選しません。受取済みメールも残り、未受取報酬はタブの目印で確認できます。

## ステージとランダム装備

ステージ7～12に固有の名称・目標・敵の強さを設定しました。12は「極北の決戦」。クリアで次へ進み、13以降は名称・6種類のイメージ絵を繰り返しながら難易度を上げます。イメージ絵は既存6枚を再利用し、戦闘の背景は3Dです。

各クリアで武器・防具・サポートから装備1個をランダム獲得。種類・レアリティは抽選時に確定して保存し、再起動で再抽選しません。

| ステージ | ドロップするレアリティ | 装備の種類 |
| --- | --- | --- |
| 1～3 | ノーマル | 基本3種 |
| 4～6 | ノーマル～グッド | 全6種 |
| 7～9 | グッド～レア | 全6種 |
| 10～12 | レア～エピック | 全6種 |
| 13～15 | エピック～レジェンド | 全6種 |
| 16以降 | レジェンド | 全6種 |

同じ種類・同じレアリティの装備3個を合成して1段階強化。装備中の素材は合成後の装備へ引き継ぎます。各スロット1つを装備でき、威力・初期人数・連射へ反映します。

## Unityで開く・検証

Unity 6.3 LTS `6000.3.26f1`。Unity Hubで `SquadRush` を追加し、`Squad Rush > Play Prototype`。Windowsではルートの `Start-SquadRush.cmd` からも起動できます。

`SquadRushPrototype` は再生成用ソースキット。`Initialize-Prototype.ps1` はシーンを作り直すため、既存編集は先に保存してください。Android Build Support（SDK / NDK / OpenJDK）とWeb Build Supportを使用します。iPhoneネイティブ用にはMacのXcodeと署名設定が別途必要です。

ゲーム処理148件・Playモード100件、計248件が成功。390×844の画面で文字の収まり・下部タブ・抽選・保存・メール・難易度別ドロップを確認しました。検証記録と画像は `SquadRush/Verification/`。実機のAndroid・iPhone・Safari・性能確認は未実施です。

データは端末内のPlayerPrefs／ブラウザのIndexedDBに保存するオフライン試作です。Androidとブラウザの保存は別で、オンラインメール配信・クラウドアカウント連携はありません。

人物・装備・風景のイラストは生成素材、3Dモデルと23種類のUIアイコンはローカル生成です。素材の指示・記録はVerification内に保存。Tripoの生成・処理クレジット消費は0。フォントはNoto Sans CJK JP（SIL OFL）、ライセンスは `SquadRush/Assets/Fonts/LICENSE.txt`。
