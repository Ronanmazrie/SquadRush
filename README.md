# スクワッド・ラッシュ / Squad Rush

敵を自動射撃しながら、部隊を左右に動かして仲間を増やす縦画面のUnityゲーム試作です。加算・倍率ゲート、数字付きの箱、敵の大群、終盤のボス戦を実装しています。広告・課金はありません。

## スマホで遊ぶ

AndroidではAPKをダウンロードしてインストールします。iPhone・Android・PCではブラウザ版も利用できます。

- [遊ぶ・ダウンロードのページ](https://ronanmazrie.github.io/SquadRush/)
- [Android版APKとリリース情報](https://github.com/Ronanmazrie/SquadRush/releases/tag/v0.10.0)

AndroidアプリはAndroid 8.0以降のARM64端末向けです。iPhoneではSafariからブラウザ版を開きます。Android用APKはiPhoneにインストールできません。iPhone用ネイティブアプリは未配布です。

## 遊び方

0.10.0では、装備に白（ノーマル）・緑（グッド）・青（レア）・紫（エピック）・金（レジェンド）の5段階を追加しました。同じ種類・同じレアリティを3個消費すると、1段階上の装備を1個入手します。効果は基本値の1・2・3・5・8倍です。装備中の素材を合成した場合は強化後の装備へ自動で引き継ぎます。最高レアリティは合成できません。クリア報酬は再クリアでも1個ずつ受け取れます。

装備一覧は5列の小さなアイコンと縦スクロールに変更し、レアリティ別の個数・装備中・合成可能を表示します。詳細では合成コストと強化後の効果を確認できます。旧版の所持品・装備・ステージ進行は引き継ぎます。ガチャは準備中です。

ホームとステージ選択は3D兵士の代わりにステージ絵を表示します。ステージ1～6に異なる6枚（砂漠・森林・雪原を各2枚）を用意し、7以降は6種類のロケーションを繰り返します。ステージ番号・難易度・進行は継続します。画像の生成指示と保存先は `SquadRush/Verification/stage-art-prompts.json` に記録しています。


0.7.0では、ホームと装備画面の配置を整理しました。画面下の常設タブでガチャ・出撃・装備を切り替え、ホーム中央の出撃ボタンからすぐ遊べます。ステージは上部のステージ名から選択できます。ステージ選択では解放済みのステージへ出撃でき、クリアすると装備を入手します。「装備」では中央の兵士の周囲に3つの装備枠を置き、その下のアイコン一覧から詳細を開いて装備・解除でき、威力・初期人数・連射速度に効果があります。所持品と装備状態は端末内に保存されます。既存のプレイヤーにはクリア済みステージ分の装備を付与します。ガチャは準備中の画面のみで、抽選・消費・課金は実装していません。

0.9.0では、装備画面中央の人物と6種類の装備をアニメ調イラストに変更しました。装備枠・所持品・詳細で同じアイテム絵を使い、所持状態と入手先、現在の同種装備との差分、実際の能力値を確認できます。戦闘の兵士は3Dのままです。ホームは0.10.0でステージ絵へ変更しました。素材と生成指示は `SquadRush/Verification/equipment-art-notes.md` に保存しています。

0.8.0では、兵士を曲面で構成したモデルへ更新しました。顔にあご・鼻・目を付け、ヘルメット・服・手足・靴の輪郭を丸くし、歩行時の上下動も抑えています。モデルはローカルで生成し、Tripoの無料診断のみを利用しました。生成・処理のクレジット消費は0です。

通常敵の基本HPは3です。ステージごとの増加幅と時間経過の補正は従来どおりで、基本武器は3発、威力2の武器は2発で序盤の敵を倒せます。

路面・土・縁石の模様も背景や白線と同じ速度でスクロールします。ホーム・一時停止ではスクロールを止め、出撃時に位相を初期化します。

仲間の上限は1000人です。青いBOXは仲間補給、金色は威力、緑色は連射です。壊した武器BOXの効果は部隊全体に適用され、画面上部で確認できます。BOXの強化は次のステージ・再挑戦では初期状態に戻り、装備画面で付けた装備の効果は残ります。BOXの武器強化は各5段階で、最大時の同種BOXは仲間補給になります。

岩や木には色むら、土汚れ、樹皮、苔などを加え、地面と縁石にも濃淡を付けました。ステージ1は砂漠、2は森林、3は雪原。その後もテーマを切り替えながら進みます。景色の種類・場所・向き・大きさは挑戦ごとに変わり、流れ去った景色も再抽選します。敵やゲートの並びも固定していません。背景は48個の枠と共有メッシュを使い回します。

人数と攻撃力は1000人まで反映します。描画は最大96体、1回の一斉射撃は最大40本の代表弾にまとめ、各弾が担当する人数分のダメージを持ちます。人数が増えた分の攻撃力を切り捨てず、描画・アニメーション・当たり判定の量を抑えています。

ホームでステージを選んで出撃し、指を左右にドラッグして部隊を移動します。射撃は自動です。加算・倍率ゲートを通り、箱を撃破して仲間を増やしてください。仲間が0人になると同じステージを再挑戦できます。ステージ終盤のボスを倒すとクリアとなり、「次のステージへ」で先へ進みます。ステージの長さは40～58秒＋ボス戦で、難易度は徐々に上がります。PCではマウス、左右矢印、A / Dでも遊べます。

進行はクリア時に端末内へ自動保存し、次回は続きから再開できます。ブラウザ版は同じブラウザ・同じ配信元のIndexedDBへ保存します（[Unity PlayerPrefsの説明](https://docs.unity3d.com/ja/current/ScriptReference/PlayerPrefs.html)）。Androidアプリの保存とは別です。

## Unityで開く

Unity 6.3 LTS `6000.3.26f1` を使用します。このリポジトリの `SquadRush` フォルダーをUnity Hubへ追加して開き、上部の `Squad Rush > Play Prototype` を選びます。WindowsでUnityを標準インストール場所へ導入している場合は、ルートの `Start-SquadRush.cmd` からも開けます。

Android用のビルドにはAndroid Build Support、SDK / NDK、OpenJDKが必要です。ブラウザ版にはWeb Build Supportが必要です。対応モジュールを導入後、`Squad Rush > Distribution` のメニューから配布用ビルドを作成できます。

## 開発と検証

- `SquadRush/Assets/Scripts/`：ゲーム処理、日本語HUD、共有モデル生成と兵士アニメーション。
- `SquadRushStage.cs` / `SquadRushScenery.cs`：ステージ設定・進行保存と景色の自動生成。
- `SquadRush/Assets/Resources/*.shader`：兵士の色・陰影と半透明エフェクト。
- `SquadRush/Assets/Editor/SquadRush/`：シーン生成、検証、起動、配布用ビルド。
- `SquadRushEquipment.cs` / `SquadRushFrontEnd.cs`：装備の入手・保存・効果と、ホーム・ステージ・装備・ガチャ準備中の画面。
- `SquadRush/Verification/`：ゲーム処理76ケースと再生モード68ケースの検証記録、画面プレビュー。
- `SquadRush/Builds/Android/`：このPCで作成したAPKとSHA-256（Git管理対象外。GitHub Releasesで配布）。
- `SquadRushPrototype/`：プロジェクト再生成用のソースキット。
- `docs/`：GitHub Pagesの配布ページとブラウザ版。

Editor内の検証に合格しています。ブラウザ版はスマホサイズのPCブラウザで起動・移動・射撃・一時停止・再挑戦を確認済みです。Android APKは署名・対応OS・CPU・アライメントの確認に合格しています。スマホ実機での性能・操作は未検証です。

## 素材

戦闘のキャラクターと背景はオリジナルのプログラム生成モデルです。装備画面の人物と装備絵は内蔵画像生成ツールで作成し、素材・生成指示を `SquadRush/Verification/equipment-art-notes.md` に記録しています。参考広告の画像・動画・3Dモデルはゲームへ取り込んでいません。日本語フォントはNoto Sans CJK JP（SIL Open Font License）を使い、ライセンスを `SquadRush/Assets/Fonts/LICENSE.txt` に含めています。Unity TextMeshPro付属フォントのライセンスも対応する素材フォルダーに含めています。
