SQUAD RUSH · 試作 0.3.0

仲間を増やして、
敵の大群を突破しよう。

左右に動いて、増加ゲートを選ぼう。
味方が増えるほど、弾も増える。最後はボスに挑戦！

ブラウザで遊ぶ Android版をダウンロード

広告・課金なし。ブラウザ版はAndroid・iPhone・PCで試せます。AndroidアプリはAndroid 8.0以降のARM64端末向けです。

グラフィックを更新しました

兵士の輪郭、ヘルメットの反射や装備をさらに精細に。体の形に沿った影、ゲートのガラス反射、サボテン・岩・街灯が並ぶ砂漠の道路で、立体感を強めました。

遊び方

  1. 「スタート」を押す。
  2. 指を左右にドラッグして移動。PCは左右キーでも操作できます。
  3. 射撃は自動。加算・倍率ゲートや箱で仲間を増やそう。
  4. 仲間が0人になると敗北。60秒後に出るボスを倒せばクリア！

スマホでの起動

Android：APKをダウンロードし、ダウンロード一覧から開いてインストールします。許可の確認が表示された場合は、このアプリをインストールする提供元を確認してください。

iPhone：Safariで「ブラウザで遊ぶ」を開いてください。配布中のAPKはAndroid専用です。iPhone用のネイティブアプリはまだ配布していません。

初回のブラウザ版は読み込みに時間がかかります。実機の性能によって動作が変わるため、これは確認用の試作です。
